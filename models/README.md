# 本项目人脸模型

模型为单类人脸检测 YOLOv8n。这里整理权重和 NCNN 静态尺寸导出，
便于从源码仓库恢复部署所需文件；不包含训练集、测试集或采集人像。

| 路径 | 用途 |
| --- | --- |
| `face_yolov8n/best.pt` | 本项目已训练的 PyTorch 权重；PC 推理或重新导出使用 |
| `face_yolov8n/320/model.ncnn.param`、`.bin` | 已验证的 320×320 板端基线 |
| `face_yolov8n/192/`、`224/`、`256/` | 同一权重的小尺寸速度试验导出 |
| `SHA256SUMS` | 以本目录为起点校验模型内容 |

导出时记录的环境为 Ultralytics 8.4.135、pnnx 20260526、NCNN
1.0.20260526；板端库使用 NCNN 20260526，Cortex-A9 NEON、无 Vulkan，
双线程版使用 NCNN simpleomp。不要把模型尺寸与摄像头/PC 画面尺寸混淆：
模型输入可变，采集输出仍是 640×480 BGR24。

320 模型来自已验证的共享部署目录，其权重 SHA256 应为
`763469a0d1e821686d0f17c3bd1b37e2e2e39023684179e2f7bba77af899359d`，
参数文件 SHA256 应为
`fdeca3c6a48921d30c613e20edcea602d00ba8c49c512bc9e5462ec1dccd244c`。
其余模型和 `best.pt` 来自本地 2026-10-13 速度试验快照。

PC 上小测试集的对照记录：

| 输入 | PyTorch mAP50 | PyTorch mAP50-95 | NCNN mAP50-95 | 输出形状 |
| --- | --- | --- | --- | --- |
| 320 | 0.995 | 0.9628 | 已有板端基线 | `[1,5,2100]` |
| 256 | 0.995 | 0.9636 | 0.9636 | `[1,5,1344]` |
| 224 | 0.995 | 0.9726 | 0.9726 | `[1,5,1029]` |
| 192 | 0.995 | 0.9577 | 0.9577 | `[1,5,756]` |

该测试集只有 108 张图片、每张一个标注人脸，不能代表多人、遮挡、
微小人脸或低光环境。Cortex-A9 性能应以板端日志为准。

部署时把选定目录中的两个 NCNN 文件复制到运行包对应的
`face-model/`（320）或 `face-model-192/`、`face-model-224/`、
`face-model-256/`，完整步骤见 `linux/studyboard_ncnn_face/`。
模型及数据的使用条件还需遵守来源许可，见根目录 `THIRD_PARTY_NOTICES.md`。
